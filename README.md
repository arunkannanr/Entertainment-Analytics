# Entertainment Analytics

An analytics project exploring Netflix titles and Spotify tracks through data cleaning, exploratory analysis, SQL, and Power BI visualizations.

## Project layout

- `data/raw/`: source datasets
- `data/cleaned/`: prepared datasets used for analysis
- `notebooks/`: cleaning, EDA, SQL, and visualization notebooks
- `sql/`: reusable SQL queries
- `dashboard/`: Power BI dashboard file
- `images/`: exported charts and dashboard preview
- `report/`: final report and presentation

## Getting started

1. Put the source CSV files in `data/raw/`.
2. Run `notebooks/01_data_cleaning.ipynb`.
3. Use the cleaned data in the remaining notebooks and SQL scripts.
4. Refresh the Power BI dashboard using the cleaned files.
